# DS1 PTDE Any% TAS

TAS of PTDE Any% as of September 2026.

Uses:

* [SoulsTAS](https://github.com/Vinjul1704/SoulsTAS) by Virazy
* [souls-tas-scripting](https://github.com/helloeloise/souls-tas-scripting) by Eloise

Structure:

Full Any% TAS will be contained in `ds1anytas.stas`. Individual sections are in `ds1anytas` folder. Each section has its own file with 1 single function. Each file will be imported in `ds1anytas.stas` and the functions called in order. This should result in the full TAS by the end at which point only `ds1anytas.stas` needs to be converted via souls-tas-scripting to a .tas file that can then be played via SoulsTAS.

Character creation already exists to provide an example.
